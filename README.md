# SQL Sales Analysis Dashboard

## Project Overview
An interactive Sales Analysis Dashboard developed using MySQL and Microsoft Power BI to analyze sales performance and generate business insights.

## Tools Used
- MySQL
- Microsoft Power BI
- SQL
- Data Visualization

## Key Features
- Total Sales, Total Orders, and Total Customers KPI cards
- Monthly Sales Analysis
- Sales by Product Category
- Total Sales by Year
- Top Products by Sales
- SQL queries using JOIN, GROUP BY, aggregate functions, and sorting

## Database Tables
- Customers
- Products
- Orders
- Order Items

## Project Files
- SQL_Sales_Analysis_Dashboard.pbix — Power BI dashboard
- sales_analysis.sql — SQL analysis queries

## Objective
To analyze sales data, identify top-performing products, and present key business metrics through an interactive dashboard.
